# Web de Antonio López Sánchez

Web de autor de Antonio López Sánchez (La Habana, 1973): escritor de fantasía heroica, poeta y periodista cubano. Premio La Rosa Blanca de la UNEAC 2012 por *Las guerreras de la luz*.

Sitio estático: HTML, CSS y JS propios, sin frameworks ni dependencias externas. Tipografías (Besley y Archivo variables) y carátulas autohospedadas; cero requests a terceros. Dirección visual: la web como número especial de una revista literaria cubana, impresa en tres tintas.

- `index.html`, `styles.css`, `app.js`: el sitio completo.
- `fonts/`, `img/`: tipografías woff2 y cubiertas reales en WebP.
- `PRODUCT.md`: verdad de producto (datos verificados y ausencias que no se fabrican).
- `DESIGN.md` y `.impeccable/design.json`: sistema de diseño registrado.

Producido por [Index01](https://index01.net). Las sinopsis actuales son provisionales y están etiquetadas; se sustituirán con el material oficial del autor.
